# Первый этап ребрендинга — 15.11.2026

Основание изменения клиентского кода: прямое поручение владельца на переводы, единый стиль иконок и восемь отмеченных экранов.

## Реализация

- Тёмная иконка приложения сохранена без изменений. Оригинальный алмаз сохранён byte-for-byte.
- Воспроизводимый экспорт 46 PNG по ролям; прозрачная маска Premium исправлена после обнаружения белого квадрата.
- Синяя палитра цены/капсулы/эмиттеров подарков и платных реакций; белый алмаз в кнопке отправки и значке лидеров.
- Готовые валютный hero и платная реакция из Web; подарки 3/6/12 месяцев из того же серверного набора, что использует iOS.
- Crystal Piece в 23 парах en/ru строк. В collectible-info заменён старый символ TON на готовый валютный алмаз.
- 36 macOS aliases сохраняют исходный lookup fallback и несовместимые legacy plain/plural families. TL constructors, номера слоёв, денежные значения и действия отправки не изменены.

- `a84640a`: отдельный пакет Crystal Piece. TeamCity 4156, build child 4154; image `sha256:17e031f1d09bbfbaeeb61469a7deb0a0085d0d4787a1b3ccde0431dd199db2fe`.
- Runtime translations generation 18: ready 1/1, observed 18, restartCount 0 на момент проверки, фактический digest совпал с TeamCity.
- Перед каждым apply выполнен preview с rollback. Первый пакет добавил 3096 строк/форм, брендовый — 46. Повтор каждого дал 0 additions, без движения sequence (97 и 98).
- RPC full-pack/difference e2e через тестовую сессию: сохранены 8162 прежних en keys и 8329 ru keys, значения и все существующие формы неизменны. Новые поля доставлены; difference от исходной версии сходится с full pack, в том числе при уменьшении content-hash version.
- Слои 224 и 226 получили тот же корректный пакет. Остальные 23 macOS языка и проверенный iOS en пакет не изменились. Это проверка конкретных старых слоёв и языковых контрактов, не заявление о полном регрессе каждого старого приложения.
- Guard SQL не обновляет существующие строки, approved/custom values или tombstones и не запускает full seed.

При диагностике до финального выпуска два чрезмерно тяжёлых read-only eval запроса привели к OOM restart старого экземпляра translations. От этого способа отказались; дальнейшая диагностика выполнялась ограниченным SQL в транзакции с rollback. Финальная реплика после выпуска стабильна; пользовательские строки не были перезаписаны. Не повторять выборку всех переводов в Erlang с попарным обходом.
